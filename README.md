# Gravity

A modern and flexible theme for Ghost with powerful homepage sections,
multiple post layouts, and full control through theme settings.

------------------------------------------------------------------------

## ✨ Features

-   Featured posts slider\
-   Tag-based homepage sections\
-   Multiple post & card layouts\
-   Light / Dark / User-controlled mode\
-   Newsletter & authors section\
-   Contact page with optional form

------------------------------------------------------------------------

## 📁 Theme Structure

-   `default.hbs` -- main layout\
-   `index.hbs` -- homepage\
-   `post.hbs` -- single post\
-   `page.hbs` -- pages\
-   `tag.hbs` -- tag archive\
-   `author.hbs` -- author archive

------------------------------------------------------------------------

## ⚙️ Customization

All settings are available in Ghost Admin → Design → Customize

You can control: - Homepage sections\
- Post layouts (global + per post)\
- Header & footer\
- Colors and appearance

------------------------------------------------------------------------

## 🏷️ Internal Tags

Used to control sections: - `#recommended` -- recommended posts\
- `#categories-posts` -- tag section header\
- `#category` -- category section\
- `#authors-section` -- authors section

------------------------------------------------------------------------
